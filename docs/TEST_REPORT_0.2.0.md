## 实机集成测试

1. 保存原有 3 个计划的 GUID、名称、当前计划及完整可见/隐藏设置输出。
2. 从当前计划复制临时计划，用包含中文、空格、括号、引号、&、!、% 的名称，核对全部设置一致。
3. 切换到设置等同于原计划的副本，并立即恢复原来的活动计划；之后才修改副本。
4. 重命名临时计划，验证备份和名称读回。
5. 修改临时计划的显示关闭时间，交流 300→600、直流 120→480，读回核对。
6. 真实写入另一交流值后注入直流失败，验证交流值恢复、直流值保留。
7. 修改幻灯片放映枚举，验证另一侧未变。
8. 导出再导入为新 GUID，比较所有设置，不自动启用。
9. 导入修改前自动备份，恢复出修改前的交流/直流值。
10. 导入损坏文件被拒绝，未覆盖已有计划。
11. 删除第一个测试副本，核对删除和备份。
12. 删除第二个测试副本，核对删除和备份。
13. 删除第三个测试副本，核对删除和备份。
14. 核对原有计划的数量、GUID、名称、全部可见/隐藏设置输出和活动选择与测试前一致。

测试前后活动计划均为“节能”。未修改原有三个计划的设置，未改注册表隐藏属性。测试过程创建的计划均已清理；临时备份保留在工作目录供检查。

## 启动窗口与 CMD

最终入口是无控制台的 Windows GUI 启动器，不调用 CMD。它以 CreateNoWindow 启动系统 PowerShell。最终启动报告必须同时满足 `Visible=true`、`NativeVisible=true`、`ConsoleAttached=false`，以及真实内容已加载。

启动测试检查的是应用自己的窗口及进程，不是用同名窗口或“进程仍在运行”来推断成功。测试进入消息循环后自动关闭，没有执行电源计划写入。

最后一次桌面查看被用户按 Esc 停止，已停止继续操作窗口；不把这次桌面查看计为视觉验收通过。上述程序内启动检查和功能测试已独立完成。

## 未覆盖和剩余限制

补充回归（2026-09-23）：用户继续报告旧异常和 CMD 窗口后，确认默认名称 EXE 仍是旧版。现已将默认入口及默认源码更新，与已测试的版本文件哈希一致。直接对默认 EXE 再次完成 174 次选择、960 条界面断言及实际启动检查，主窗口可见且 `ConsoleAttached=false`。本次没有再次修改系统电源计划；原有 14 项写入测试结果仍对应此前记录的运行。此次发布遗漏单独记为 BUG-018，证据见 `测试证据_0.2.0/default-entry-verification.txt`。
