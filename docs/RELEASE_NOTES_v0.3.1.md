# 电源计划管理器 v0.3.1

本版本汇集 0.3.0 与 0.3.1 的界面、配色和隐藏设置更新，保留原有计划管理、备份、校验与失败恢复能力。

## 下载与使用

下载 `PowerPlanManager-v0.3.1.exe`，关闭旧版本窗口后运行。无需安装 Python 或 .NET SDK，使用 Windows 自带的 PowerShell 5.1 和电源接口。权限不足时按提示以管理员身份重新运行；没有自动按操作提权。

- `PowerPlanManager-v0.3.1.exe.sha256.txt`：EXE 完整性校验。
- `PowerPlanManager-GitHub-source.zip`：源码、构建脚本、测试和最新文档，包含包内文件哈希清单。

## 主要更新

- 首页计划选择、启用和刷新同排，常用设置按插电/电池值对齐；计划管理默认收起，统一按钮尺寸与间距。
- 高级设置按分类浏览，新增名称/分类/GUID 搜索和“包含系统隐藏项”；筛选保留草稿，保存应用当前项。
- 常用时间提供易读输入及原始值编辑；未知设置仍依赖可靠元数据校验。
- 外观支持跟随系统、浅色、深色、系统强调色和六组配色，自动保存偏好。
- Windows 隐藏项管理可显示所选设置或分类，先保存原属性，保留其他属性位，并在恢复前检查外部冲突。显示属性对本机所有计划共用；解除隐藏不代表硬件或策略允许使用该功能。
- 新增项目进度汇总，以及 100 项安全与健壮性测试方案、执行台账和优先复现流程。

## 验证与已知限制

发布前默认回归通过：核心 57/57、GUI 972 断言、外观/草稿 48 检查、隐藏项 254 检查，以及进程通信、超时、布局与真实只读加载。已验证环境为 Windows 11 x64、Windows PowerShell 5.1。

最终 EXE 已重新解包核对脚本与启动器，默认 EXE 与版本 EXE 一致；包内 GUI 回归、实际可见窗口、无附带控制台及正常退出验证通过。本次沿用已验证的 0.3.1 二进制，没有重新编译或改变程序代码。

隐藏属性写入与恢复采用模拟验证，尚未完成管理员原生实机测试。跨设备、多 DPI 和人工完整端到端交互仍未全面验证。专项安全检查目前完成文档与源码审查，100 项用例尚未执行；风险线索不是已确认漏洞，本次发布不表示完整安全验收通过。

仍为单项保存，尚无自动提权、完整崩溃恢复中心和异步操作流程。EXE 未签名。详细进度见源码包中的 `docs/PROGRESS_0.3.1.md`、`docs/TEST_REPORT_0.3.1.md` 和 `docs/SECURITY_TEST_PLAN.md`。
