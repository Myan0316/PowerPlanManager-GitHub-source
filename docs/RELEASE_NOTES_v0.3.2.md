# 电源计划管理器 v0.3.2

下载 `PowerPlanManager-v0.3.2.exe`，关闭旧版本后重新打开。主窗口与底部版本号均为 **0.3.2**。配套提供 EXE SHA-256 文件和 `PowerPlanManager-GitHub-source.zip`，源码包包含逐文件校验清单及 LICENSE。

## 修复

- 恢复切换计划时的一次查询、双缓冲、离屏构建常用设置和按钮状态更新优化，减少窗口与按钮闪烁。设置解析失败时仍保留技术原文。
- 保留原始数值输入选项修复：仅在支持友好时间预设的可编辑设置中显示，其他设置及无选择状态隐藏。
- 恢复被撤回的回归测试，新增原始数值输入选项显示、隐藏及切回检查。
- 清理 Bug 日志中的合并冲突标记，补齐源码和发布附件的一致性检查。

## 本地与 GitHub 不一致的原因

`66b62f7` 撤回了此前的防闪烁代码和测试，但本地 `dist` 仍保留撤回前的修复程序。与此同时，GitHub 的 v0.3.1 附件发布于 2026-09-27 09:59 UTC，早于这两项修复；推送源码没有重新上传附件。v0.3.2 从恢复后的源码重新构建，并使用新的版本号和 Release，避免混淆同名旧包。

`scripts/publish-github.ps1` 要求工作区干净、当前提交已在远程 main 上，然后重新构建、验证 EXE、导出源码、上传草稿并下载核对每个附件；全部通过后才公开并设置为最新版。已有标签和发布不会被覆盖。

## 验证

Windows 11 x64、Windows PowerShell 5.1 下完整构建通过：核心 57/57、GUI 975 条断言、外观及输入 52 项、隐藏项 254 项检查，以及进程通信、超时和三种窗口尺寸测试。包内脚本和启动器哈希一致，解包回归通过；默认 EXE 与版本 EXE 相同，实际启动窗口可见、显示 0.3.2、加载 3 个计划、无附带控制台并正常退出。

本轮没有执行真实电源设置或隐藏属性写入。人工目视闪烁验收、跨设备和多 DPI 仍需验证；现有同步操作、单项保存、无自动按操作提权及未签名限制继续保留。
