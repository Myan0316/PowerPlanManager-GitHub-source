# 0.3.1 界面与隐藏设置验证

日期：2026-09-27。本地构建；本轮未提交、推送或创建 GitHub Release。保留 0.3.0 原文件及历史报告。

## 改动

- 首页采用横向计划操作行、AC/DC 对齐表格、折叠管理区；按钮统一尺寸、圆角和间距，不再自动铺满整行。
- 高级双栏增加名称/分类/GUID 搜索和“包含系统隐藏项”。切换筛选保留草稿，保存仍只应用当前项。
- Windows 隐藏项管理支持选择单个设置或分类，确认影响范围后备份并清除隐藏位；支持恢复并拒绝外部冲突、损坏或跨机备份。参数数值保持原样，其他属性位保留。
- 无分类设置按根节点读取，属性缺失/非 DWORD 不强制写入。已显示的项目不重复操作。

- 解除隐藏仅改变全机共用显示属性，不等于强制启用硬件、驱动或策略不支持的能力；分类隐藏和子项隐藏分别处理。
- 当前仍按项保存；属性写入权限不足时需同一账号以管理员身份重开程序。没有实现自动按需提权。
- 原生系统不提供与第三方工具之间的原子事务；写前和写后核对能检测部分竞争，无法排除检查与写入之间的外部改变。
