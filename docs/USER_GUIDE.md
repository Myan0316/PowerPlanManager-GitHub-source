# 电源计划管理器 0.2.0

打开 `电源计划管理器.exe` 或 `电源计划管理器_0.2.0.exe`，两个文件现在内容完全一致。程序自动读取当前电脑的电源计划，不需要填写或修改 GUID。

2026-09-23 已纠正默认入口仍为旧版的发布遗漏。更新前已打开的窗口仍运行旧代码，请先关闭再重新打开；新版主窗口标题包含 `0.2.0`，设置编辑中的枚举项目使用下拉框。历史文件已归档到工作目录，不在默认入口继续使用。

启动仅显示图形界面，不创建 CMD 窗口。程序使用 Windows 自带的 PowerShell 5.1 和 powercfg；EXE 是便携打包程序，不需要安装 Python 或 .NET SDK。

## 基本操作

- 选择计划后点击“启用选中计划”切换；完成后重新读取活动计划核对。
- “创建计划”复制选中的计划，再输入新名称。副本不会自动启用。
- “重命名”“删除”“修改设置”会先导出备份。备份失败便停止后续写入。
- 当前活动计划、系统最后一个计划不可删除。
- “导出备份”保存 `.pow` 文件；“导入计划”创建新计划，不覆盖现有计划、不自动启用。
- “恢复备份”将所选 `.pow` 恢复成新的计划，再由你决定是否启用。
- “修改设置”分别编辑接通电源和使用电池时的值；枚举用下拉选项，数值按范围和步长校验。切换行保留未保存输入，关闭前提示是否放弃。
- “刷新”重新获取状态。如果你同时用控制面板或其他软件修改计划，请重新打开编辑窗口后再写入。

## 管理员权限

查看计划可直接运行。Windows 的导出/备份等操作需要管理员特权；需要重命名、修改、删除、导入导出时，建议关闭程序，右键 EXE 选择“以管理员身份运行”，再确认 Windows 的授权提示。

本版本不会在单个操作中自动弹出 UAC。权限不足会显示具体错误和上述提示，也不会绕过备份保护。本次测试没有修改系统执行策略；脚本运行参数只影响本次 PowerShell 进程。

## 备份与错误恢复

自动备份默认位于当前运行账户的 `%LOCALAPPDATA%\PowerPlanManager\Backups`。文件名包含计划 GUID、时间和随机标识；错误提示会给出相关备份路径。

如果两项设置只写成功一项，程序会尝试恢复本次改动并读回核对。若检测到其他程序改值，或恢复操作本身失败，会保留错误和备份路径，不会声称修改成功。可先刷新检查，再用“恢复备份”恢复为新计划。

创建过程中若副本已生成但命名失败，程序会显示新 GUID，保留副本供检查；此时刷新后可重命名或删除它。

## 当前范围

设置编辑支持中文和英文 powercfg 输出；无法确认范围、当前值或枚举进制的项目只读。其他语言不猜测写入。控制面板隐藏属性的解锁、完整隐藏设置管理和界面重设计尚未实施。

硬件、驱动、固件和系统策略可能影响设置的实际效果，读回成功表示 Windows 保存了该值。系统接口不提供本程序可用的跨软件事务锁，因此请避免同时在多个工具中编辑同一项。

系统命令有超时保护；多步操作仍同步执行，处理中界面可能暂时不响应。单次命令超时会报告结果未确认，请先刷新检查。

本机已验证 Windows 11 10.0.26200、Windows PowerShell 5.1；其他系统、硬件和 DPI 的覆盖范围见测试报告。

- `BUG_FIX_LOG.md`：逐项问题、原因、修复和验证记录。
- `TEST_REPORT_0.2.0.md`：本次验证范围、结果和限制。
- `电源计划管理器_0.2.0.exe.sha256.txt`：发布文件校验值。
- `PowerPlanManager-GitHub-source.zip`：GUI、核心逻辑、无控制台启动器、构建脚本和回归测试。

源码包解压后，使用 Windows PowerShell 5.1 执行 `scripts/build.ps1` 构建。构建自动执行只读及模拟测试，并验证打包内容、实际窗口启动、无控制台和退出行为。`test-live.ps1` 的真实写入测试必须显式启用，且要求管理员权限；只操作自己创建的临时计划并在最后核对原有状态。

仓库的源码位于 src/，文档位于 docs/；EXE 和源码 ZIP 由构建/导出命令生成在 dist/，通过 GitHub Releases 分发。历史本机测试证据只保存在本地归档，公开仓库提供摘要报告。
