# 电源计划管理器 0.3.1

打开本地 `dist/电源计划管理器.exe` 或 `dist/电源计划管理器_0.3.1.exe`，两个文件内容完全一致。程序自动读取当前电脑的电源计划，不需要填写或修改 GUID。本轮没有更新 GitHub Release，上次核对的远程版本为 0.2.0。

更新前已打开的窗口仍运行旧代码，请先关闭再重新打开；新版标题包含 `0.3.1`，左侧可进入首页、备份与恢复、外观。旧版带版本号文件继续保留，默认入口已同步新版。

启动仅显示图形界面，不创建 CMD 窗口。程序使用 Windows 自带的 PowerShell 5.1 和 powercfg；EXE 是便携打包程序，不需要安装 Python 或 .NET SDK。

## 基本操作

- 首页下拉框选择要查看的计划。顶部“正在使用”表示真正生效的计划；选择其他计划不会自动启用。
- 点击“使用这个计划”才会切换；完成后重新读取活动计划核对。
- 常用表格按列显示本机提供的屏幕/睡眠时间，点“调整”打开单项编辑。时间可选分钟或“从不”，非预设当前值也会保留；需要精确秒数时勾选原始数值输入。
- “高级设置”按左侧类别浏览，右侧选择参数，再分别调整接通电源与使用电池的值。枚举直接显示名称；未知定义只读。
- “预览并保存这一项”会展示目标计划、旧值与新值；确认并成功备份后才写入。一项一项保存，切换分类/设置保留其他草稿，关闭前询问是否放弃未保存输入。
- 首页“展开计划管理”中，“复制为新计划”复制选中的计划，再输入新名称。副本不会自动启用。
- “重命名”“删除计划”和保存设置会先导出备份。备份失败便停止后续写入。
- 当前活动计划、系统最后一个计划不可删除。
- 左侧“备份与恢复”中，“导出选中计划”保存 `.pow` 文件；“导入计划文件”“从备份恢复”创建新计划，不覆盖现有计划、不自动启用。
- “刷新”重新获取状态。如果你同时用控制面板或其他软件修改计划，请重新打开编辑窗口后再写入。
- 展开计划管理后的“技术详情”保留计划 GUID 和系统原始输出，排查问题时再查看。

## 查看和开启隐藏设置

进入“高级设置”，勾选“包含系统隐藏项”。程序重新读取本机提供的完整参数，可搜索名称、分类或 GUID；这一勾选不修改 Windows 显示属性。具有可靠定义的隐藏参数可沿用普通参数的预览、备份、保存和读回流程。取消勾选或过滤掉某项不会丢失它的草稿。

如果需要让 Windows 控制面板显示某一项，点击“管理 Windows 隐藏项”，搜索并选中具体功能，再点“显示所选项”。确认框说明影响范围；成功后请关闭并重新打开 Windows 的高级电源设置。只清除隐藏标记，电源参数值保持原样。

“整个分类”和“单个设置”分别列出。解除分类隐藏会影响该分类的入口，但不会改写子项的隐藏标记；若设置受到分类隐藏影响，需要另外选中分类操作。显示属性是本机全局属性，会影响所有计划的显示。解除标记后，Windows、硬件或厂商策略仍可能限制某个功能的显示和实际效果。

原始显示属性保存在当前账号的 `%LOCALAPPDATA%\PowerPlanManager\VisibilityBackups`。选择同一项并点“恢复原隐藏状态”，即可恢复原属性；重启程序后仍可恢复。属性已被其他软件修改、备份损坏或来自其他电脑时，会拒绝覆盖。此备份不能用 `.pow` 的“从备份恢复”入口导入。属性缺失、类型异常的节点不会被强制改写；权限不足时以管理员身份重新运行，使用同一 Windows 账号以访问原备份。

## 调整外观

左侧进入“外观”。明暗模式可选跟随系统、浅色或深色；颜色组合可选跟随系统强调色，以及海洋蓝、森林绿、鸢尾紫、暖琥珀、玫瑰红、石墨灰。明暗与颜色可独立搭配。

选择后立即生效并自动保存。跟随系统时，程序会在运行期间检测 Windows 应用配色变化；无需更改 Windows 设置来单独给本程序换色。启用 Windows 高对比度时优先采用系统颜色。

偏好保存在 `%LOCALAPPDATA%\PowerPlanManager\appearance.json`，前一次保存保留为 `.bak`。配置损坏会回退到系统跟随；无法保存时显示提示，本次预览仍生效。系统消息框、文件选择器等部分原生区域仍由 Windows 绘制。

## 管理员权限

查看计划可直接运行。Windows 的导出/备份等操作需要管理员特权；需要重命名、修改、删除、导入导出时，建议关闭程序，右键 EXE 选择“以管理员身份运行”，再确认 Windows 的授权提示。

本版本不会在单个操作中自动弹出 UAC。权限不足会显示具体错误和上述提示，也不会绕过备份保护。本次测试没有修改系统执行策略；脚本运行参数只影响本次 PowerShell 进程。

## 备份与错误恢复

自动备份默认位于当前运行账户的 `%LOCALAPPDATA%\PowerPlanManager\Backups`。文件名包含计划 GUID、时间和随机标识；错误提示会给出相关备份路径。

如果两项设置只写成功一项，程序会尝试恢复本次改动并读回核对。若检测到其他程序改值，或恢复操作本身失败，会保留错误和备份路径，不会声称修改成功。可先刷新检查，再用“恢复备份”恢复为新计划。

创建过程中若副本已生成但命名失败，程序会显示新 GUID，保留副本供检查；此时刷新后可重命名或删除它。

## 当前范围

设置编辑支持中文和英文 powercfg 输出；无法确认范围、当前值或枚举进制的项目只读。其他语言不猜测写入。0.3.1 增加隐藏参数和显示属性管理，仍按项保存，不支持一键批量解除所有隐藏项。首页不会展示本机不存在的常用项；无电池设备看到的电池值仅为计划中保存的配置。

硬件、驱动、固件和系统策略可能影响设置的实际效果，读回成功表示 Windows 保存了该值。系统接口不提供本程序可用的跨软件事务锁，因此请避免同时在多个工具中编辑同一项。

系统命令有超时保护；多步操作仍同步执行，处理中界面可能暂时不响应。单次命令超时会报告结果未确认，请先刷新检查。

本机已验证 Windows 11 10.0.26200、Windows PowerShell 5.1；其他系统、硬件和 DPI 的覆盖范围见测试报告。

- `TEST_REPORT_0.3.1.md`：本次验证范围、结果和限制；0.2.0 报告保留为历史。

- `PowerPlanManager-GitHub-source.zip`：GUI、核心逻辑、无控制台启动器、构建脚本和回归测试。

源码包解压后，使用 Windows PowerShell 5.1 执行 `scripts/build.ps1` 构建。构建自动执行只读及模拟测试，并验证打包内容（包含新增的 `PowerPlan.UI.ps1`）、实际窗口启动、无控制台和退出行为。`test-live.ps1` 的真实写入测试必须显式启用，且要求管理员权限；只操作自己创建的临时计划并在最后核对原有状态。

仓库的源码位于 src/，文档位于 docs/；EXE 和源码 ZIP 由构建/导出命令生成在 dist/，通过 GitHub Releases 分发。历史本机测试证据只保存在本地归档，公开仓库提供摘要报告。
