# 项目进度汇总与 0.3.1 发布范围

核对日期：2026-09-27。当前应用版本为 **0.3.1**；技术栈为 Windows PowerShell 5.1、WinForms、系统 powercfg/电源 API、C# 无控制台启动器和 IExpress 便携打包。

许可补充（2026-09-28）：已采用 [自定义许可](../LICENSE)，允许免费使用，禁止收费销售，对外分发修改版须公开对应源码；以下功能和测试状态仍以原核对日期为准。

## 已实现

| 范围 | 当前能力 |
| --- | --- |
| 计划管理 | 自动读取本机计划与 GUID；刷新、切换、复制、重命名、删除；保护活动计划和最后一个计划 |
| 导入与恢复 | `.pow` 导出/导入；恢复创建新 GUID，不自动启用；修改、改名、删除前备份 |
| 参数编辑 | 单项 AC/DC 编辑；范围、步长、枚举验证；未知或不完整定义只读；写前冲突检查、写后核对与部分失败恢复 |
| 首页与高级页 | 简洁首页、插电/电池对齐、折叠管理；分类高级页、搜索、草稿保留、常用时间与原始值输入 |
| 外观 | 跟随系统、浅色、深色；系统强调色及六组配色；偏好持久化与损坏回退 |
| 隐藏参数 | `/qh` 浏览系统隐藏参数，可靠定义可编辑；显示属性支持选定设置/分类解除隐藏、先备份及冲突检查后恢复 |
| 工程交付 | 源码/测试/文档分离、便携 EXE、SHA-256、源码包、包内一致性与默认入口验证 |

显示属性对本机所有计划共用，清除隐藏位不保证硬件、驱动或策略允许使用相应功能。分类与子项分别操作，参数数值不随显示属性操作一起改变。
